Design System Agnóstico

Tokens semánticos --ds-*, registry copy-paste y playground vivo — sin runtime de framework. Pensado para productos con la densidad visual de Linear y la claridad tipográfica de Geist.

$ npx rzz-ui add button

Instalación CLI

Localmente usá el CLI del monorepo. El comando público es npx rzz-ui add ….

1. npm install · 2. npm run build:tokens · 3. npx rzz-ui add button (o npm run rzz-ui -- add button) copia el componente a src/components/ui/.

Incluí dist/css/variables.css en tu página antes de los CSS del registry. El playground de desarrollo sigue en index.html en la raíz.

Arquitectura de Tokens

Pipeline DTCG → Style Dictionary → CSS/TS. Capas primitive + semantic; aliases cortos para sombra, z-index y motion.

Color / superficie: --ds-semantic-surface-*, --ds-semantic-content-*, --ds-semantic-action-*.

Elevación: --ds-shadow-xs|sm|md. Capas: --ds-z-banner … --ds-z-tooltip. Motion: --ds-duration-*, --ds-ease-standard.

Colores & Superficies

Tokens vivos sobre el tema activo. Copiá el nombre CSS para usarlo en componentes.

--ds-semantic-surface-canvas

surface / página

--ds-semantic-surface-card

surface / card

--ds-semantic-surface-elevated

surface / elevated

--ds-semantic-action-primary-default

action / primary

--ds-semantic-action-danger-default

action / danger

--ds-semantic-border-subtle

border / subtle

Tipografía

Escala Inter con tracking negativo. Mono para código.

Display 3xl --ds-primitive-font-size-3xl-font-size
Heading xl --ds-primitive-font-size-xl-font-size
Body md — texto de interfaz --ds-primitive-font-size-md-font-size
Mono xs — tokens & snippets --ds-primitive-font-family-mono
