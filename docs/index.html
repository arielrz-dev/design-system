Design System Agnóstico

Tokens semánticos --rzz-*, registry copy-paste y playground vivo — sin runtime de framework. Pensado para productos con la densidad visual de Linear y la claridad tipográfica de Geist.

$ npx github:arielrz-dev/design-system add button

Instalación CLI

Se distribuye desde GitHub, sin publicar en npm. Corré el CLI desde la raíz de tu proyecto: copia los componentes y sus dependencias a src/ui/.

Usar en tu proyecto

  1. npx github:arielrz-dev/design-system add button dialog instala uno o varios componentes. Con --path components/ui cambiás el destino.
  2. Para fijar una versión: npm i -D github:arielrz-dev/design-system#v0.1.0 y después npx rzz-ui add button.
  3. Cargá dist/css/variables.css antes de los CSS de los componentes, y los .js como <script type="module">.

Desarrollar este repo

  1. npm install y npm run build:tokens
  2. npm run docs:dev sirve docs y playground en http://localhost:4173
  3. npm run rzz-ui -- add button instala en el src/ui/ de este repo (fuente canónica: registry/ui/).

Arquitectura de Tokens

Pipeline DTCG → Style Dictionary → CSS/TS. API pública: --rzz-surface-*, --rzz-content-*, --rzz-border-*, --rzz-action-*, space/radius/text, shadow/z/duration.

Color / superficie: --rzz-surface-*, --rzz-content-*, --rzz-action-*.

Elevación: --rzz-shadow-xs|sm|md. Capas: --rzz-z-banner … --rzz-z-tooltip. Motion: --rzz-duration-*, --rzz-ease-standard.

Colores & Superficies

Tokens vivos sobre el tema activo. Copiá el nombre CSS para usarlo en componentes.

--rzz-surface-canvas

surface / página

--rzz-surface-card

surface / card

--rzz-surface-elevated

surface / elevated

--rzz-action-primary-default

--rzz-action-danger-default

action / danger

--rzz-border-subtle

border / subtle

Tipografía

Escala Inter con tracking negativo. Mono para código.

Body md — texto de interfaz --rzz-text-md
Mono xs — tokens & snippets --rzz-font-mono
